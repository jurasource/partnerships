## Spacing Scale

Declared values (multiples of 4). Confirmed from existing codebase pattern (`px-6 py-6 gap-1 gap-2 py-3`).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge internal padding (`px-1.5 py-0.5`) |
| sm | 8px | Compact inline spacing (`gap-2`), button gaps |
| md | 16px | Default element spacing, form field gaps |
| lg | 24px | Page content padding (`px-6 py-6`) |
| xl | 32px | Section vertical rhythm |
| 2xl | 48px | Empty-state vertical centering (`py-24` outer) |
| 3xl | 64px | Page-level minimum heights |

Exceptions:

- Touch target minimum 44px for icon-only buttons (e.g. row refresh, row actions)
- Header row vertical padding: `py-3` (12px) — matches established table pattern
- Badge `text-xs` with `px-1.5 py-0.5` — fractional Tailwind values; keep consistent with existing badges

## Component Inventory

### Phase 3 new components — specification

#### 1. Firm Profile Page (`/firms/[id]`)

Layout: full `<main>` with sticky `<header>` matching existing page header pattern.

```
<header px-6 py-6 border-b bg-white>
  <h1 text-[28px] font-semibold>  {Firm canonical name}
  <capability badges>              Nuclear / Infrastructure / Consultancy
  <staleness badge>                Inherited StalenessBadge
  <refresh button>                 "Refresh Research" — blue-600 CTA
</header>

<div px-6 py-6 flex gap-6>
  <section flex-1 min-w-0>        Findings by topic (accordion/tabs)
  <aside w-72 shrink-0>           Citation panel
</div>

<section px-6 pb-6>               Contract History table (full width)
```

Firm name in `<h1>` is the authoritative canonical name from the DB — no truncation.

#### 2. Findings by Topic (`findings-by-topic`)

Use shadcn `Tabs` component (already installed). One tab per research topic.

- Tab label: topic name
- Tab content: finding body text at `text-sm` weight 400, line-height 1.5
- If no finding for topic: empty state copy (see Copywriting section)
- Finding source type badge inline below each finding body
- Citation link: external URL rendered as `text-blue-600 underline text-xs` with lucide `ExternalLink` h-3 w-3 inline icon

#### 3. Citation Panel (`citation-panel`)

Sidebar aside, 288px (w-72) fixed width.

- Section heading: "Sources" — `text-sm font-semibold text-neutral-700`
- Separator between structured and AI entries
- Each entry: source URL (truncated to 40 chars with tooltip for full URL), source type badge, date retrieved
- Structured API entries grouped first, AI entries second
- "Verified API" badge: `bg-sky-50 text-sky-700 border-sky-100 text-xs`
- "AI Research" badge: `bg-violet-50 text-violet-700 border-violet-100 text-xs`

#### 4. Contract History Table (`contract-history-table`)

TanStack Table (matches existing table pattern). Columns:

| Column | Width | Notes |
|--------|-------|-------|
| Title | flex-1 | Contract/notice title, truncated at 60 chars with Tooltip |
| Date | 120px | Award date, `en-GB` format ("14 Jun 2026"), `font-mono text-xs` |
| Value | 100px | GBP formatted (£1.2m), right-aligned, `font-mono text-xs` |
| Source | 80px | "CF" (Contracts Finder) or "FTS" (Find a Tender) badge |

Row hover: `hover:bg-neutral-50 transition-colors` (matches firms-table pattern).
Empty state: inline within table body (see Copywriting section).

#### 5. Comparison Table — Phase 3 enhancements

Extend existing `ComparisonTable` component. Do not rebuild.

New columns to add:

## Interaction Contract

### Firm name → profile navigation

- In comparison table: firm canonical name is a `<Link href="/firms/[id]">` rendered as `text-blue-600 hover:underline text-sm font-medium`
- Clicking opens the firm profile page (App Router route `/firms/[id]/page.tsx`)
- Back navigation: browser back button (no explicit "Back to Dashboard" needed for MVP)

### Capability tag filter (DASH-02)

- Filter bar renders above the comparison table
- Each tag button is a toggle: click to activate, click again to deactivate
- Multiple tags can be active simultaneously (OR logic — show firms matching any active tag)
- Zero active tags = show all firms (unfiltered)
- Active state visual: tag button adopts filled background of its semantic color
- No URL state in Phase 3 MVP (client state only)

### Column sort (DASH-03)

- All columns sortable except the Actions column
- Sort indicator: ChevronUp / ChevronDown / ChevronsUpDown (existing pattern from firms-table)
- Single-column sort (no multi-sort in Phase 3)

### Research refresh (DASH-04)

- "Refresh Research" button appears in both:
  1. Comparison table Actions column (icon-only, RefreshCw h-4 w-4, tooltip "Refresh Research")
  2. Firm profile page header (text button "Refresh Research", blue-600, with RefreshCw icon)
- On click: calls existing `runResearch` server action (already built in Phase 2)
- During execution: button disabled, RefreshCw icon animates (`animate-spin`), staleness badge updates to running state
- On completion: toast success/error via `sonner` Toaster (existing pattern)
- No confirmation dialog — refresh is non-destructive

### Profile tab switching (PROF-01)

- Tab selection is immediate, no loading state (findings already cached in DB)
- Active tab: shadcn Tabs default active styling (underline on base-nova preset)
- If finding body is long (>500 chars): show full text without truncation (this is an intelligence tool — no progressive disclosure of findings)

### Contract history (PROF-03)

- Rendered as a TanStack table below the findings/citation panel section
- Default sort: award date descending (most recent first)
- No pagination for Phase 3 MVP (max ~50 rows per firm expected)
- Long titles truncated with shadcn Tooltip showing full title on hover

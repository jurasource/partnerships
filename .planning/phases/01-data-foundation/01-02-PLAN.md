|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Tampering | updateFirm/deleteFirm/topic actions | mitigate | Zod-validate inputs; use parameterised Drizzle `eq(table.id, id)` — no raw SQL interpolation (prevents SQL injection) |
| T-01-06 | Elevation of Privilege | delete actions | accept | Single-user local tool, no auth model (REQUIREMENTS: multi-user out of scope); destructive actions gated behind AlertDialog confirmation in UI |
| T-01-07 | Spoofing | server action invocation | accept | Local-first single-user; Next.js Server Actions are same-origin POST with built-in action-id protection; no additional CSRF surface at this scale |
</threat_model>

<objective>
Wire the Wave 1 research worker into a triggerable, observable backend path: a `runResearch` server action that enqueues a durable job and fires a non-blocking POST to a new `/api/research/run` route handler, which runs the worker, transitions the job through running → done | failed, and stamps `firms.lastResearchedAt` on success. A `GET /api/research/status/[jobId]` endpoint returns the job row plus a derived "N/7 topics complete" count for client polling.

Purpose: This delivers the user-triggerable, progress-visible research path (RES-01 trigger, RES-02 polling, RES-06 cache-on-trigger, RES-07 last-researched stamp) and locks the job-lifecycle integrity invariant (E9 / FM5 / D-05): no job ever freezes in `running`, and partial findings survive a mid-run failure. The fire-and-forget shape (D-03) keeps it Railway-extractable — only the POST target URL would change.

Output: After this plan, research is fully runnable end-to-end from a server action; Wave 3 only adds the UI surface that calls it.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → server action (runResearch) | firmId is the only input; looked up against the DB, never interpolated into a host/scheme |
| server action → POST /api/research/run | Local same-origin fire-and-forget; body is { firmId, jobId }, Zod-validated at the route |
| client poll → GET /api/research/status/[jobId] | jobId path param looked up via getJob; no other DB mutation reachable from this endpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Denial of Service | Job stuck in `running` (FM5) | mitigate | POST handler always transitions to done OR failed in try/catch; integration test (E9) asserts no terminal-less job |
| T-02-06 | Tampering | Malformed POST body to /api/research/run | mitigate | Zod-validate { firmId, jobId }; return 400 on invalid body before any job mutation |
| T-02-07 | Information Disclosure | Status endpoint leaks data | accept | Single-user local tool, no auth surface (REQUIREMENTS out-of-scope: no multi-user/permissions); endpoint returns only the job row + a count |
| T-02-08 | Repudiation | Lost partial findings on failure | mitigate | Worker inserts per-topic; failure path does NOT roll back; test asserts retained count (D-05) |
| T-02-SC | Tampering | npm installs | n/a | No new package installs in this plan (all installed in 02-01) |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client component → runResearch server action | firmId passed from the rendered row; the action re-validates the firm server-side |
| client poll → GET /api/research/status/[jobId] | jobId comes from the action's return; read-only status fetch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | Denial of Service | Orphaned setInterval poll (never cleared) | mitigate | Poll clears on done/failed AND on component unmount (useEffect cleanup); no poll runs without a jobId |
| T-02-10 | Tampering | Client triggers research on a firm with no CH number | mitigate | Button disabled when companiesHouseNumber is null; runResearch also rejects server-side with the CH-number-required error (defense in depth) |
| T-02-11 | Information Disclosure | Secrets in client bundle | mitigate | No API keys touched in client components; all secrets stay in the server-only worker/clients from Waves 1-2 |
| T-02-SC | Tampering | shadcn `progress` install | mitigate | Official shadcn registry, no third-party registry (UI-SPEC §Registry Safety) — vetting gate not applicable |
</threat_model>

## What Was Built

**`src/app/(app)/firms/page.tsx`**
- Added two-query pattern: `allFirms` (existing) + `memberships` join of `firmGroups` and `groups` tables via `eq(firmGroups.groupId, groups.id)`
- Built a `Map<firmId, Array<{id, name}>>` for O(1) lookup
- Maps `allFirms` into `firmsWithGroups` (each firm plus `groups` array) and passes to `<FirmsTable data={firmsWithGroups} />`

**`src/components/firms/firms-table.tsx`**
- Exported `FirmWithGroups = Firm & { groups: Array<{ id: string; name: string }> }`
- Changed `FirmsTableProps.data` and all `ColumnDef` generics from `Firm` to `FirmWithGroups`
- New "Groups" column (after Capabilities, before Research): renders amber pill `<Link href="/groups/[id]">` per group; empty state shows muted "None"
- Lifted filter state: `selectedGroupIds`, `selectedCapabilities`, `researchStatus`
- Derived `allGroups` (unique id+name from `data[].groups`) via useMemo
- Computed `filteredData` useMemo applying OR-logic group filter, OR-logic capability filter, and research status filter (30-day stale threshold)
- Passed `filteredData` (not `data`) to `useReactTable`; sorting intact
- Renders `<FirmsFilterBar />` above table div; empty-rows guard added

**`src/components/firms/firms-filter-bar.tsx`** (new)
- "use client" component with controlled props interface
- Groups multi-select: `DropdownMenu` + `DropdownMenuCheckboxItem` per group; trigger shows count badge when active
- Capabilities multi-select: same pattern over `["Nuclear", "Infrastructure", "Consultancy"]`
- Research status single-select: Base UI `Select` with options All / Researched / Not researched / Stale (>30 days)
- "Clear filters" ghost button shown only when any filter is active

# Phase 03.1 Plan 02: Groups UI Summary

Groups management area built end-to-end: navbar entry, list page with firm counts, create/delete dialogs, and detail page with inline rename and membership management.

## What Was Built

### Task 1: Groups list + nav item (commit db39fc0)

- Added `LayersIcon` import and `Groups` entry to `NAV_ITEMS` in `app-navbar.tsx`, positioned between Firms and Topics
- Created `/groups` RSC (`src/app/(app)/groups/page.tsx`) using Drizzle `leftJoin` + `count()` to aggregate firm membership counts; ordered by group name
- Created `GroupFormDialog` (`src/components/groups/group-form-dialog.tsx`) — single-field dialog calling `createGroup` server action; toast on success; inline error on failure
- Created `GroupsTable` (`src/components/groups/groups-table.tsx`) — plain Table with name as blue Link to `/groups/[id]`, firm count label, View link, and AlertDialog delete via `deleteGroup`

### Task 2: Group detail page (commit 87c413e)

- Created `/groups/[id]` RSC (`src/app/(app)/groups/[id]/page.tsx`) — async params, `notFound()` guard, member firms via `innerJoin` on `firmGroups`, non-member firms computed from all firms minus member set
- Created `GroupDetailClient` (`src/components/groups/group-detail-client.tsx`) with three regions:
  1. Inline rename: edit/save/cancel state machine calling `updateGroup`
  2. Member list: each firm with Remove button calling `removeFirmFromGroup`
  3. Add-firm picker: Base UI `Select` listing non-members, calling `addFirmToGroup` on selection; hidden when all firms are members

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Base UI Select generic type inference**
- **Found during:** Task 2 TypeScript check
- **Issue:** `onValueChange={(value) => {...}}` produced TS error because TypeScript inferred `Value = {}` (empty object type) rather than `string` for the untyped Select generic
- **Fix:** Typed the callback parameter explicitly: `(value: string | null) => void`
- **Files modified:** `src/components/groups/group-detail-client.tsx`

**2. [Rule 2 - Pattern] Button asChild not supported by Base UI**
- **Found during:** Task 1 implementation
- **Issue:** Base UI `ButtonPrimitive` does not expose an `asChild` prop; attempting `<Button asChild><Link>View</Link></Button>` would not compile
- **Fix:** Replaced with a styled `<Link>` using inline Tailwind classes matching the ghost button style
- **Files modified:** `src/components/groups/groups-table.tsx`

Inherited from Phase 3 (no changes). Reproduced for executor reference.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), badge internal padding (`px-1.5 py-0.5`) |
| sm | 8px | Compact inline spacing (`gap-2`), button gaps |
| md | 16px | Default element spacing, form field gaps |
| lg | 24px | Page content padding (`px-6 py-6`) |
| xl | 32px | Section vertical rhythm |
| 2xl | 48px | Empty-state vertical centering |
| 3xl | 64px | Page-level minimum heights |

Exceptions:

- Touch target minimum 44px for icon-only buttons (carry-forward from Phase 3)
- Header row vertical padding: `py-3` (12px) — matches established table pattern
- Conflict matrix cells: minimum 40px square (`min-w-10 min-h-10`) to keep grid readable

## Component Inventory

### 1. Analysis Page (`/analysis`)

New full-page route. Three sections, each occupying full content width with `px-6 py-6` padding and `xl` (32px) vertical gap between sections.

```
<header px-6 py-6 border-b bg-white>
  <h1 text-[28px] font-semibold>  "Cross-Cutting Analysis"
  <p text-sm text-neutral-500>    "Ownership, conflicts, and partnerships across all researched firms."

<section px-6 py-6>               Ownership Roll-Up
<separator />
<section px-6 py-6>               Conflict Matrix
<separator />
<section px-6 py-6>               Partnership Evidence Table
```

#### 1a. Ownership Roll-Up (`analysis/ownership-rollup`)

Four stat tiles in a horizontal flex row (wrap on narrow viewport):

- "Total firms": integer count
- "UK-owned": integer (green-100 bg tile)
- "Foreign-owned": integer (amber-100 bg tile) with country breakdown tooltip listing ISO codes and counts
- "Ownership unknown": integer (neutral-100 bg tile)

Each tile: `rounded-lg border p-4 flex flex-col gap-1`. Count rendered at `text-xl font-semibold`, label at `text-xs font-semibold uppercase tracking-wide text-neutral-500`.

Empty state: if zero firms have ownership records — "No ownership data yet. Run research for at least one firm to enable ownership analysis."

#### 1b. Conflict Matrix (`analysis/conflict-matrix`)

Grid layout (CSS grid, not TanStack Table). Rows and columns are firm canonical names.

- Header row and header column: firm names at `text-xs font-semibold` — truncate to 16 chars with Tooltip showing full name
- Header cell background: `bg-neutral-50`
- Diagonal cells (firm vs itself): `bg-neutral-100` — render "—"
- Flagged conflict cell: `bg-red-50 border border-red-200` — render a badge showing conflict type ("Audit" or "Competitor") at `text-xs`
- Non-conflicted cell: `bg-white` — render empty (no "No conflict" text — keep matrix scannable per D-04 specifics)
- Cell minimum size: `min-w-10 min-h-10` (40×40px)
- Matrix scrollable horizontally on overflow (`overflow-x-auto` wrapper)

Empty state (fewer than 2 researched firms): "Add at least two researched firms to generate a conflict matrix."

#### 1c. Partnership Evidence Table (`analysis/partnership-table`)

TanStack Table. Columns:

| Column | Width | Notes |
|--------|-------|-------|
| Firm A | 160px | Canonical name, link to `/firms/[id]` in blue-600 |
| Firm B | 160px | Canonical name, link to `/firms/[id]` in blue-600 |
| Type | 100px | "Co-supplier" or "JV" badge |
| Evidence | flex-1 | Short evidence string (contract title or JV announcement), truncated at 60 chars with Tooltip |
| Source | 80px | "OCDS" or "AI Research" badge, matching established palette |
| Date | 100px | ISO date formatted as `en-GB` ("14 Jun 2026"), `font-mono text-xs` |

Default sort: Type ascending (Co-supplier before JV), then Date descending.

Empty state: "No partnership evidence found across researched firms."

Empty state (researched, no collaboration found): "No collaboration history detected — based on available research."
Empty state (not researched): "Run research first to enable collaboration history."

#### 2d. Conflicts of Interest — Firm Perspective (`firms/[id]/firm-conflicts-list`) — ANAL-01

Empty state (researched): "No conflicts of interest detected — based on available research. This does not constitute a legal clearance."

#### 2e. Known Partnerships — Firm Perspective (`firms/[id]/firm-partnerships-list`) — ANAL-02

Empty state (researched): "No partnership evidence found for this firm."
Empty state (not researched): "Run research first to enable partnership detection."

## Interaction Contract

### Conflict matrix navigation

- Clicking a flagged cell does not navigate. The cell badge is not a link.
- The conflicting firm names (row/column headers) are links to `/firms/[id]` — `text-xs text-blue-600 hover:underline`.
- Matrix is read-only; no edit interactions in Phase 4.

### Ownership badge — comparison table

- Badge is non-interactive (not a button).
- Tooltip on hover shows source string (see Component Inventory §3 above).
- Column is sortable so users can group non-UK firms — sort click target is the column header, not the badge.

### Risk flag severity ordering

- Rendered High → Medium → Low (most severe first).
- No interactive sort by user — order is fixed by severity.
- No collapse/expand — all flags shown (intelligence tool, progressive disclosure not appropriate per Phase 3 precedent).

### Recompute trigger (ANAL-04)

- Cross-cutting analysis jobs are enqueued automatically when a research job completes (D-10). No user-visible trigger for the extraction pass.
- The `/jobs` page shows both job types so users can observe both passes completing.
- No separate "Re-run analysis" button on the profile or /analysis page — refresh is triggered via the existing "Refresh Research" button on the firm profile.

### Empty states — "no research yet" vs "researched, nothing found"

Both cases require distinct copy (see Copywriting Contract below). The UI must not conflate "no data because never run" with "no data because nothing was found."

### Companies House external link

- CH number in the ownership section is a `<a href="https://find-and-update.company-information.service.gov.uk/company/{number}" target="_blank" rel="noopener noreferrer">` with `ExternalLink` icon (h-3 w-3, inline, `ml-0.5`).
- Rendered as `text-blue-600 underline text-sm font-mono`.
- If the firm has no CH number, render the label value as "Not recorded" in `text-neutral-500` (no link).

### /analysis page — section headings and anchors

Three sections each have a visible `<h2>` heading with `id` attributes for deep linking:

- `id="ownership"` — "Ownership"
- `id="conflicts"` — "Conflicts of Interest"
- `id="partnerships"` — "Partnerships"

No visible anchor links needed for Phase 4 MVP.

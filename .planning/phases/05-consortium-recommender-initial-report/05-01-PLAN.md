<objective>
Build the deterministic scoring engine vertical slice: Zod request/response schemas, the pure-function scorer (signal scorers + conflict exclusion + combination ranking), the combinations helper, the `/api/recommend` POST route, and the E1–E8 Vitest eval suite. After this plan, a `curl` POST to `/api/recommend` returns a ranked, conflict-free, fully-explainable consortium recommendation — the testable core of CONS-01 through CONS-05.

Purpose: This is the foundation every other Phase 5 slice consumes. The scorer is a pure function (no DB, no Next.js imports) so the entire requirement set is verifiable in Vitest with plain-object fixtures in <100ms. The API route is the integration boundary that loads DB signals once and calls the scorer.

Output: `src/lib/recommend/{schemas,scorer,combinations}.ts`, `src/app/api/recommend/route.ts`, and `src/lib/recommend/__tests__/{scorer,schemas}.test.ts`.
Decisions implemented: D-03 (computation via /api/recommend route), D-04 (one primary + 2 ranked alternatives), D-05 (all four secondary signals: partnerships, UK ownership/NSI, contract relevance, risk flags), D-08 (API respects lockedFirmIds for lock-and-recompute).
</objective>

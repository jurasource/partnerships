## Critical Blockers

### B-01 — Production Build Failing

**File:** `src/components/firms/firm-form-dialog.tsx:193`
**Error:**
```
Type error: Type 'string | number | bigint | boolean | Element | ...' is not assignable
to type 'ReactElement | ComponentRenderFn | undefined'.
Type 'string' is not assignable to type 'ReactElement | ...'
```
**Root cause:** `FirmFormDialogProps.trigger` is typed as `React.ReactNode` (which includes string/number/boolean) but shadcn Base UI's `DialogTrigger.render` only accepts `ReactElement | ComponentRenderFn | undefined`.
**Fix:** One-line change — update the prop type:
```typescript
// firm-form-dialog.tsx, FirmFormDialogProps interface
trigger?: React.ReactElement;   // was: React.ReactNode
```
**Why it's a blocker:** `npm run build` exits 1. Phase 2 cannot begin with a broken production build.

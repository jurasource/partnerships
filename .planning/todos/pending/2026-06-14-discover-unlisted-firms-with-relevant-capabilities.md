## Problem

The user's firm list is manually curated, but there may be other firms operating in the UK civil nuclear / defence space that have the capabilities being tracked (Nuclear, Infrastructure, Construction) that aren't currently in the seed list. A user of this tool has no way to discover these gaps.

## Solution

Add a "discover firms" feature: given the current capability tags and sector context, run an AI-assisted search to surface firms that operate in the same space but aren't on the user's list. Present as suggestions the user can review and add. This is a side quest — not blocking Phase 1–3 core functionality.
